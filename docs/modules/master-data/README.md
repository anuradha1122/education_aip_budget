# Organisation and Master Data

## Purpose

Maintain the organisational and reference data used by the programme
budget system.

## Current implementation

- Offices database table
- Office model

## Planned

- Office management screens
- User-to-office assignments
- Roles and permissions
- Server-side office restrictions
- Audit history
- Applicable Excel and PDF outputs

The provincial office and seven zonal office names and codes must be
confirmed before creating their records.
